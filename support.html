FAQ

Is Papyrus Papers cloud-first?

No. Papyrus Papers is local-first. Your library database, PDFs, notes, search indexes, backups, and project evidence live on your device unless you explicitly export, share, or sync them.

What is the difference between Copy Into Library and Keep PDFs In Place?

Copy Into Library stores the PDF inside Papyrus-managed library storage. Keep PDFs In Place leaves the file where it already lives and stores a system bookmark so Papyrus can reopen it later.

Which metadata sources are used?

Papyrus Papers can look up metadata through Crossref, arXiv, Semantic Scholar, OpenAlex, OpenLibrary, NCBI / PubMed / PMC identifier services, Zenodo, and DOI links. It also reads embedded PDF metadata without a network request.

Does Papyrus upload PDFs for metadata lookup?

No. Metadata lookup sends identifiers or search terms such as DOI, title, author, ISBN, PMID, or arXiv ID. PDFs are not uploaded for ordinary metadata enrichment.

How does sync work?

Sync is optional and uses a WebDAV server you configure. Papyrus Papers can keep dated restore points so you can inspect a previous synced library before restoring it.

What is the Evidence Board?

The Evidence Board is a project-level workspace for claims, quotes, page numbers, interpretations, section roles, confidence scores, and citation keys. It is meant to keep the reasoning behind a draft attached to the papers that support it.

Can one paper appear in several projects?

Yes. A paper can have different project-specific roles and evidence without changing its global library metadata.

What can Papyrus export?

Individual papers and projects can export in open formats such as BibTeX, RIS, CSL JSON, Markdown, and project bundles. Export preflight can flag sparse metadata, duplicate cite keys, missing PDFs, and other handoff problems.

Does Papyrus Papers require an account?

No Papyrus Papers account is required.

Bug Reports

A useful bug report includes:

  • macOS or iPadOS version
  • Papyrus Papers version and build number
  • Whether the PDF was copied into the library or kept in place
  • Whether sync, metadata enrichment, project export, or App Store purchase state was involved
  • Step-by-step reproduction notes
  • Screenshots or screen recordings when they clarify the problem

Do not post private PDFs, WebDAV passwords, access tokens, private server URLs, or confidential research material in a public issue.

Security

If you believe you found a security issue, avoid posting exploit details publicly. Email zdfu189@gmail.com with a short description and a safe way to reproduce or discuss it.
